# She Can Connect

A simple responsive contact form website created for the Full Stack Development Internship Task by She Can Foundation.

## Features

* Name Field
* Email Field
* Message Field
* Submit Button
* Success Message after submission
* Responsive UI Design
* Basic Form Validation using HTML

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

```text id="c9q7tw"

```

## How to Run the Project

1. Download or clone the repository
2. Open the project folder
3. Run `index.html` in any browser
